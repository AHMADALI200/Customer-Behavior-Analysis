# Customer Behavior Analysis 

## Project Overview
This project focuses on analyzing customer behavior to uncover insights related to purchasing patterns, subscriptions, demographics, and revenue trends. The analysis is presented through an interactive dashboard designed to support data-driven business decisions.

---

## Tools & Technologies
- **Power BI** – Dashboard creation and data visualization  
- **Python** – Data cleaning and analysis  
- **SQL** – Data extraction and querying  
- **Pandas, NumPy** – Data manipulation  

---

## Key Insights
- Analyzed customer distribution based on **subscription status** and **gender**
- Identified **top-performing product categories** by sales and revenue
- Studied **customer age groups** to understand buying behavior
- Evaluated **average purchase amount** and **customer review ratings**

---

##  Dashboard Features
- Interactive KPIs for customer count, revenue, and ratings  
- Category-wise and age-group-wise sales & revenue analysis  
- Filters for subscription status, gender, category, and shipping type
